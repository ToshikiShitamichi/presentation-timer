# 00 要求定義（講義時間管理アプリ）

- 改訂：v1

| # | 項目 | 内容 |
|---|---|---|
| 1 | アプリ名 | 講義時間管理アプリ |
| 2 | 一言で何をするか | 講義中に、予定では現在どのスライドの説明をしているのか見えるためのツール |
| 3 | 誰が使うか | 私 |
| 4 | 困りごと | 講義中に時計と進行表を見比べないと、予定では今どこを話すべきかが分からない |
| 5 | 成功の状態 | 次の4つが画面に表示される。休憩の時間帯は「【休憩】」と表示する。<br>・現在のブロックのスライド範囲（例：スライド1〜8枚目）<br>・講義内容（内容欄の1行目の見出し。例：【01 JavaScriptを動かしてみよう（説明）】）<br>・現在時刻<br>・現在のブロックの残り時間 |
| 6 | いつ・どこで・どの端末で | 講義中／私のスマホ端末で／机に置いて見るだけ（講義中は操作しない） |
| 7 | やらないこと | ・実際のスライド（PowerPoint・Googleスライド）との連動<br>・複数の講義の保存<br>・PCとの同期<br>・1枚ずつのスライド番号の推定（範囲をそのまま表示する） |
| 8 | MVPで最低限ほしいこと | ・講義進行表のテキストを貼り付けて取り込む（タブ区切りで、セル内に改行がある形式。ヘッダー行があれば読み飛ばす）<br>・時計の時刻と各行の開始時刻を比べて、現在のブロックを決める<br>・休憩の行も1つのブロックとして扱う<br>・上の4項目を表示する<br>・講義の終わりは「最後の行の開始時刻＋所要時間」で計算する（例：16:37＋0:08＝16:45） |
| 9 | 制約 | ・PWAで作る<br>・取り込むデータは講義進行表の列構成に従う（開始時間・所要時間・ステップ・進め方・手順・使用ツール・資料・ハマりポイント・時間調整ポイント） |
| 10 | 参考 | （未入力） |
