# 02 機能設計と業務ルール

## 機能

### F-001 進行表の取り込み
- きっかけ：画面での操作
- 対応する要件：R-002-1、R-001-1、R-003-3、R-001-2、R-001-3
- 処理の流れ：
  1. 1. 講義進行表のテキストを貼り付けて取り込む
  2. 2. タブ区切りで列に分け、1行を1つのブロックとして読み込む。引用符で囲まれたセルの中の改行は、そのセルの一部として扱う
  3. 3. ヘッダー行があれば読み飛ばす
  4. 4. 各列を、開始時間・所要時間・ステップ・進め方・手順・使用ツール・資料・ハマりポイント／フォロー方法・時間調整ポイントの順に読み込む
  5. 5. 進め方・手順欄が「【休憩】」の行は、休憩のブロックとして読み込む
  6. 6. 講義の終わりの時刻を、最後の行の開始時刻＋所要時間で計算する

### F-002 現在のブロックの判定
- きっかけ：一定時間ごとの自動実行
- 対応する要件：R-003-1、R-006-1、R-003-2
- 処理の流れ：
  1. 1. 現在時刻を取得する
  2. 2. 現在時刻が、ある行の開始時刻以上で次の行の開始時刻より前なら、その行を現在のブロックとする
  3. 3. 現在時刻が、最後の行の開始時刻以上で講義の終わりの時刻より前なら、最後の行を現在のブロックとする

### F-003 画面表示の更新
- きっかけ：一定時間ごとの自動実行
- 対応する要件：R-004-1、R-004-4、R-004-2、R-006-1、R-004-3、R-005-1
- 処理の流れ：
  1. 1. 現在時刻を表示する
  2. 2. 現在のブロックが休憩のブロックなら「【休憩】」と表示する
  3. 3. 現在のブロックがあれば、使用ツール・資料欄に書かれたスライド範囲をそのまま表示する
  4. 4. 現在のブロックがあれば、進め方・手順欄の1行目の見出しを講義内容として表示する
  5. 5. 現在のブロックがあれば、現在のブロックの開始時刻＋所要時間までの残り時間を表示する

### F-004 講義の登録
- きっかけ：画面での操作
- 対応する要件：R-007-1、R-007-2
- 処理の流れ：
  1. 1. 日付と進行表のテキストを入れて講義を登録する
  2. 2. 進行表のテキストを、進行表の取り込みと同じ流れで読み込む
  3. 3. 日付と進行表を、1つの講義として保存する
  4. 4. すでに同じ日付の講義が登録されていれば、同じ日付の講義として追加で保存する

### F-005 登録した講義の一覧表示
- きっかけ：画面での操作
- 対応する要件：R-008-1、R-007-3
- 処理の流れ：
  1. 1. アプリを開く
  2. 2. 保存しておいた講義を読み込む
  3. 3. 講義が登録されていれば、登録した講義を日付ごとに一覧で表示する

### F-006 講義の選択
- きっかけ：画面での操作
- 対応する要件：R-008-2
- 処理の流れ：
  1. 1. 一覧から講義を選ぶ
  2. 2. 選んだ講義の進行表で、現在のブロックの判定を始める
  3. 3. 選んだ講義の進行表で、画面表示の更新を始める

## 業務ルール

### BR-001 列の並び
- 種類：入力の制約
- 内容：取り込むテキストの列は、開始時間・所要時間・ステップ・進め方・手順・使用ツール・資料・ハマりポイント／フォロー方法・時間調整ポイントの順とする

### BR-002 セルの中の改行
- 種類：入力の制約
- 内容：引用符で囲まれたセルの中の改行は、行の区切りではなくそのセルの一部として扱う

### BR-003 ヘッダー行の読み飛ばし
- 種類：入力の制約
- 内容：取り込むテキストにヘッダー行があれば、ブロックとして読み込まない

### BR-004 休憩のブロック
- 種類：入力の制約
- 内容：進め方・手順欄が「【休憩】」の行は休憩のブロックとする

### BR-005 講義の終わりの時刻
- 種類：計算
- 内容：講義の終わりの時刻 ＝ 最後の行の開始時刻 ＋ 最後の行の所要時間（例：16:37＋0:08＝16:45）

### BR-006 現在のブロックの切り替わり
- 種類：状態の遷移
- 内容：現在時刻が、ある行の開始時刻以上で次の行の開始時刻より前の間は、その行を現在のブロックとする。最後の行は、その開始時刻以上で講義の終わりの時刻より前の間、現在のブロックとする

### BR-007 残り時間
- 種類：計算
- 内容：残り時間 ＝ 現在のブロックの開始時刻 ＋ 所要時間 − 現在時刻

### BR-008 講義の単位
- 種類：入力の制約
- 内容：1つの講義は、日付と進行表の組とする

### BR-009 同じ日付の複数の講義
- 種類：入力の制約
- 内容：同じ日付に、複数の講義を登録できる

### BR-010 登録した講義の保持
- 種類：状態の遷移
- 内容：登録した講義は、アプリを開き直しても残す

### BR-011 表示する講義
- 種類：状態の遷移
- 内容：現在のブロックの判定と画面表示には、一覧から選んだ講義の進行表を使う
